## 🧩 How I build

- **Model → data → product.** Pick the right model, ground it in real data, ship it where people already are.
- **Privacy by design.** Excel Data Insights shares column names, not cells. UsChat encrypts end to end.
- **Small, working integrations first.** Each one shipped and used before the next.
