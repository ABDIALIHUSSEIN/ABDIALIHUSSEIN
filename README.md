## 🧩 How I build

- **Model → data → product.** Pick the model for the job, ground it in real data, and ship it where people already are: web, mobile, or a spreadsheet.
- **Privacy by design.** Send models only what they need. Excel Data Insights shares column names, not cells; UsChat encrypts messages end to end.
- **Small, working integrations first.** One integration at a time, each one shipped and used before the next.
